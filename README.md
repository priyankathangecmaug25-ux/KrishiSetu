🌾 KrishiSetu – Smart Agriculture Service Platform

KrishiSetu is a full-stack web application designed to bridge the gap between farmers, farm workers, and machinery providers. The platform helps farmers easily hire workers, rent agricultural machinery on an hourly basis, and make secure payments online.

This project is developed using modern technologies like ASP.NET Core, Spring Boot, React, and MySQL, ensuring scalability, performance, and a user-friendly experience.

🚀 Features

👨‍🌾 Farmer Registration & Profile Management

🚜 Machinery Rental System (Hourly Rate Booking)

👷 Farm Worker Hiring & Availability Tracking

🌐 Multi-language Support (English/Hindi/Marathi)

💳 Razorpay Payment Integration

🔐 Secure Authentication & Role-Based Access Control

📦 REST APIs with Spring Boot and ASP.NET Core

🗄️ MySQL Database for Data Storage
